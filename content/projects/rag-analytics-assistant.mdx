## Problem
People wanted quick answers about their data. A plain chatbot answers confidently even when it has no grounding, and every call costs time and tokens.

## Approach
- Retrieval filtering and better chunking so the model sees the right context.
- Query normalisation plus caching for repeated questions.
- Routing to skip unnecessary model or tool calls.
- A standard evaluation workflow so prompt or model changes can't silently reduce quality.

## Outcome
Faster responses on repeated queries, steadier answer relevance, and controlled per-query cost.

## What I'd improve
- A golden-question set run on every change.
- Guardrails and audit logs for sensitive data.
