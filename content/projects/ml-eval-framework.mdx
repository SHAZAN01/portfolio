## Goal
Make model iteration safe: every result reproducible, every change compared against the last good run.

## What it does
- Config-driven experiments, so a run can be repeated exactly.
- Data versioning and metric tracking across runs.
- Automated regression tests that flag performance drops before they ship.
- Hooks for drift monitoring.

## Outcome
Less manual validation and faster, more comparable iteration cycles.
